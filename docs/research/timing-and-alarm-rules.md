# Checkbox timing and alarm rules

Research for the wayfinder ticket _Pin down the Checkbox timing and alarm rules_.
Source: the manual in the repo root (`30784_BA_Checkbox-5u1_…pdf`); page numbers are the printed page numbers.
A web search turned up no other public Pölz documentation for the device, so every gap below is a real gap.

Every rule is tagged:

- **[Manual]** — stated in the manual text.
- **[Figure]** — read off an LCD figure in the manual; the figures are illustrative and not always mutually consistent.
- **[Assumption]** — the manual is silent or contradicts itself; needs a decision (see [Open decisions](#open-decisions)).

## Notation

| Symbol   | Meaning                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------ |
| `T`      | The Trupp's Einsatzzeit in minutes (Einsatzzeit #1–#4: [01], [02], [10], [17]).                  |
| `P_N`    | Nenndruck of the chosen Atemschutzflasche type (200 or 300 bar).                                 |
| `P_0`    | Anfangsdruck entered at login.                                                                   |
| `P`      | Latest Flaschendruck entered for the Trupp.                                                      |
| `t_run`  | Elapsed **running** time of the Einsatz — simulated time (9.1) minus time spent in Bereitschaft. |
| `t_A`    | Anmarschzeit — `t_run` at the moment the Trupp was set to Einsatzziel erreicht.                  |
| `P_Ziel` | Flaschendruck entered at Einsatzziel erreicht.                                                   |
| `P_R`    | Rückzugsdruck (5.7).                                                                             |
| `R`      | Restzeit as shown on the Einsatzliste.                                                           |
| `[nn]`   | Parameter number from manual 9.1.                                                                |

"Regelzeit" in the manual (5.5.4, [06]) means the same as Einsatzzeit; the glossary lists it as an alias to avoid.

## 1. Restzeit

| #   | Rule                                                                                                                                                                                                                                                                                                                     | Source                                                                                                  |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| 1.1 | Restzeit counts down one second per second while the Trupp is not in Bereitschaft.                                                                                                                                                                                                                                       | [Manual] p. 14, 26                                                                                      |
| 1.2 | At 00:00:00 it keeps counting as a negative time, so the overdue time is visible at a glance.                                                                                                                                                                                                                            | [Manual] p. 24                                                                                          |
| 1.3 | Initial Restzeit is scaled by the Anfangsdruck: `R = T × P_0 / P_N`. Example in the figure: 30 min, 300 bar bottle, 250 bar → 00:25:00.                                                                                                                                                                                  | [Figure] p. 20, 28                                                                                      |
| 1.4 | When a new Flaschendruck `P` is entered (Druck ändern, or at Einsatzziel erreicht / Rückzug antreten), Restzeit is recomputed: `R = T × P / P_N`. The manual says only "Die neuen Druck- und Zeitinformationen werden berechnet". The p. 22 figure (295 bar → 00:28:00, not 00:29:30) does not fit this formula exactly. | **Decided** (A1)                                                                                        |
| 1.7 | The Trupp-Ansicht's Aktueller Flaschendruck is a live estimate `P = R × P_N / T`, shown in whole bar rounded down and clamped at 0 (an empty cylinder does not occur in practice). Druck ändern opens the editor at that estimate, snapped down to the [76] grid. The Rückzugsalarm compares against it (5.5).           | **Decided** (device behaviour)                                                                          |
| 1.5 | Pressure may only be raised during an Einsatz if [73] Druck vergrößerbar > 0, in steps of [73]; otherwise only lowered.                                                                                                                                                                                                  | [Manual] p. 72                                                                                          |
| 1.8 | ~~A raise via Druck ändern is capped at `P_N` + 10 % (330 bar), the same ceiling as the Anfangsdruck (1.6).~~ Replaced: every pressure editor stops at `P_N` = 300 bar, a raise via Druck ändern included.                                                                                                               | [Device]; **Decided** in _Correct the simulator against the real Checkbox_                              |
| 1.6 | ~~Anfangsdruck entry is bounded by [77]/[78]: at most +10 % / −10 % of `P_N` by default.~~ Replaced: the Anfangsdruck runs from 0 to `P_N` = 300 bar ([77] = 0 %); it opens at 300. Steps are [76] Druck-Sprunggröße. The missing lower bound is an assumption: the user did not try it on the device.                   | [Manual] p. 72–73; [Device] (300 bar); **Decided** in _Correct the simulator against the real Checkbox_ |

## 2. Alarmgrenzen #1–#4

| #   | Rule                                                                                                                                                                                                                                                                       | Source                                                                    |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 2.1 | Each Einsatzzeit has up to four Alarmgrenzen as a percentage of `T`; 0 = off. Defaults: #1 = 33 %, #2 = 66 %, #3 = #4 = 0.                                                                                                                                                 | [Manual] p. 23, 70                                                        |
| 2.2 | Alarmgrenze `g` fires when `g %` of the Einsatzzeit has elapsed (`t_run ≥ g × T`). The manual's example rounds this to 10 min (Restzeit 20 min) and 20 min (Restzeit 10 min) for 30 min; the simulator takes the percentages literally (2.6).                              | [Manual] p. 23–24                                                         |
| 2.3 | Each Alarmgrenze fires once per Einsatz, in every Einsatzstatus (Anmarsch, Einsatzziel erreicht, Rückmarsch).                                                                                                                                                              | **Decided** (A2)                                                          |
| 2.4 | ~~After a pressure change (1.4), the Alarmgrenze is measured against Restzeit.~~ Rejected: Alarmgrenzen stay on elapsed running time (2.2) regardless of pressure entries, matching FwDV 7's "Uhrzeit bei 1/3 und 2/3" (see [FwDV 7 cross-check](#11-fwdv-7-cross-check)). | **Decided** (A1)                                                          |
| 2.5 | Configured order: 1/3 and 2/3 limits follow FwDV 7.                                                                                                                                                                                                                        | [Manual] p. 23                                                            |
| 2.6 | The percentages are taken literally, not as thirds: at 30 min the Alarmgrenzen fire at `t_run` = 9:54 and 19:48.                                                                                                                                                           | **Decided** in _Settle the edge cases the verification scenarios exposed_ |

## 3. Einsatzzeit reached and overdue

| #   | Rule                                                                                                                                                                                                                                                                                                                                     | Source                                                                    |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 3.1 | When Restzeit reaches 00:00:00 an Alarm fires ("Alarm bei Erreichen der gesamten Einsatzzeit").                                                                                                                                                                                                                                          | [Manual] p. 24                                                            |
| 3.2 | After that, an Alarm repeats every [06] Alarmintervall Regelzeit minutes (manual text: "alle 5 Minuten"; range 0–60, 0 = off).                                                                                                                                                                                                           | [Manual] p. 25, 69                                                        |
| 3.3 | The repeat alarms are anchored to Restzeit values: one fires each time Restzeit crosses a multiple of −[06] (−05:00, −10:00, …). Acknowledging never shifts them. A pressure entry that jumps Restzeit across several steps fires one alarm on confirmation; missed steps are not replayed, and the next one comes at the next multiple. | **Decided** (A3)                                                          |
| 3.4 | A pressure entry that drops Restzeit to 00:00:00 or below fires the Einsatzzeit-erreicht alarm as soon as OK confirms the entry.                                                                                                                                                                                                         | **Decided** (A2)                                                          |
| 3.5 | The 00:00:00 alarm and the repeats fire in every Einsatzstatus, Rückmarsch included.                                                                                                                                                                                                                                                     | **Decided** (A2)                                                          |
| 3.6 | A pressure entry on an overdue Trupp re-arms them: Restzeit is ≥ 00:00:00 again (1.4), so the Einsatzzeit-erreicht alarm fires again when it next reaches 00:00:00, and the repeats again at each multiple of −[06].                                                                                                                     | **Decided** in _Settle the edge cases the verification scenarios exposed_ |

## 4. Bereitschaft

| #   | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Source                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 4.1 | In Bereitschaft the running Einsatzzeit stops; the display shows the last value. Monitoring resumes when the Trupp is set back to EINSATZ ("Trupp -> Einsatz").                                                                                                                                                                                                                                                                                                                                                                                            | [Manual] p. 27                                                             |
| 4.2 | A Trupp can enter Bereitschaft at login (Atemschutzträger log on while en route) or from a running Einsatz via the Trupp-Menü.                                                                                                                                                                                                                                                                                                                                                                                                                             | [Manual] p. 18–19, 27                                                      |
| 4.3 | While in Bereitschaft an Alarm sounds every [05] Alarmintervall Bereitschaft minutes (text: "alle fünf Minuten"; range 0–60, 0 = off). A Sicherheitstrupp (12.8) never gets it.                                                                                                                                                                                                                                                                                                                                                                            | [Manual] p. 28, 69; [Device] (Sicherheitstrupp)                            |
| 4.4 | The Bereitschaft interval is anchored to simulated time since the Trupp entered Bereitschaft (+5, +10, … min) and restarts on each entry. Acknowledging never shifts it.                                                                                                                                                                                                                                                                                                                                                                                   | **Decided** (A3)                                                           |
| 4.7 | While a Trupp is in Bereitschaft only the Bereitschaft alarm sounds (and for a Sicherheitstrupp nothing). Alarmgrenzen, the Rückzugsalarm and the overdue repeats pause with `t_run` and Restzeit, even for a Trupp that was already overdue.                                                                                                                                                                                                                                                                                                              | **Decided** (A3)                                                           |
| 4.5 | Because Alarmgrenzen are measured in `t_run` and the other alarm points in Restzeit, Bereitschaft shifts all pending alarm points by its duration.                                                                                                                                                                                                                                                                                                                                                                                                         | Follows from 4.1                                                           |
| 4.6 | ~~Bereitschaft means the Trupp is in a safe area, so "Trupp -> Einsatz" never restores the earlier Einsatzstatus.~~ Replaced: "Trupp -> Einsatz" **restores the Einsatzstatus the Trupp had before Bereitschaft** (Anmarsch, Einsatzziel erreicht or Rückmarsch). A Trupp that started in Bereitschaft has none and goes to Anmarsch (mode on) or Einsatzziel erreicht (mode off). Nothing is reset: the Anmarschzeit resumes, the Rückzugsdruck is kept, and a Rückzugsalarm that has fired stays fired. See [section 12](#12-einsatzstatus-transitions). | [Device]; **Decided** in _Correct the simulator against the real Checkbox_ |

## 5. Rückzugsalarm

| #    | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Source                                                                                                      |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 5.1  | The Rückzugsalarmmodus is set per Einsatzzeit: [41], [69], [70], [71].                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | [Manual] p. 70–71, 88–89                                                                                    |
| 5.2  | **Mode off:** the Trupp gets Einsatzziel erreicht at login. Only that status is available. No Anmarsch or Rückmarsch times are computed and no Rückzugsalarm fires.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | [Manual] p. 11, 20, 22, 25                                                                                  |
| 5.3  | **Mode on:** the Trupp starts in Anmarsch. The operator sets Einsatzziel erreicht, then Rückmarsch, on radio reports. Each change asks for the current Flaschendruck.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | [Manual] p. 20, 22–23, 29–30                                                                                |
| 5.4  | The Anmarschzeit `t_A` is the running time from start to Einsatzziel erreicht. It no longer feeds the Rückzugsalarm (5.5); it only splits the Trupp-Ansicht's bar (5.8).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | [Manual] p. 22                                                                                              |
| 5.5  | ~~The Rückzugsalarm fires once Restzeit falls to "die doppelte Anmarschzeit zuzüglich des eingestellten Reservedruckes": `R ≤ 2·t_A + t_res`.~~ Replaced: the Rückzugsalarm is **pressure-based**. It fires when the estimate (1.7) falls to the Rückzugsdruck: `R × P_N / T ≤ P_R`, i.e. `R ≤ P_R × T / P_N` (exact, before rounding). Example: 30 min, `P_R` = 120 bar → `R` ≤ 12:00.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | [Device]; **Decided** in _Correct the simulator against the real Checkbox_ (manual p. 25, 70–71 superseded) |
| 5.6  | ~~The Reservedruck is converted to time with the same linear model as 1.3: `t_res = [42] × T / P_N`.~~ Replaced: [42] is no longer converted to time or added on; it is the floor of the Rückzugsdruck (5.7).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | **Decided** in _Correct the simulator against the real Checkbox_                                            |
| 5.7  | ~~`P_R = [42] + 2·t_A × P_N / T`, rounded down.~~ Replaced: the Rückzugsdruck, the "Flaschendruck bei dem der Rückzugsalarm ausgelöst wird", is `P_R = max(2 × (P_0 − P_Ziel), [42])`: twice the Anmarschdruck, never below the Reservedruck. Before Einsatzziel erreicht it is the floor, 50 bar, and the Trupp-Ansicht and ALARM screen show 50 bar from login. Examples: 300 → 280 gives 50 bar (40 is below the floor); 300 → 240 gives 120 bar. All entered pressures are on the [76] grid, so `P_R` is whole bar and needs no rounding. It is not capped at `P_N`. Whenever the pressure entered at Einsatzziel erreicht is already at or below `P_R` (from 300 bar: an Anmarschdruck of 100 bar or more), the Rückzugsalarm fires immediately on OK (5.14); the user saw this on the device with an Anmarschdruck of 150 bar. Because the shown estimate is rounded down, it may read `P_R` for up to `T / P_N` (6 s at 30 min) before the alarm fires. | [Device]; **Decided** in _Correct the simulator against the real Checkbox_                                  |
| 5.11 | ~~The Rückzugsalarm stays **time-based** (5.5).~~ Replaced: the device sizes the Rückweg in pressure, twice the Anmarschdruck, which matches FwDV 7's twice the Atemluftmenge (see [FwDV 7 cross-check](#11-fwdv-7-cross-check)). The simulator still follows the device, not the regulation: the 50 bar floor and the comparison against a time-derived estimate are device behaviour.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | [Device]; **Decided** in _Correct the simulator against the real Checkbox_                                  |
| 5.12 | [82] Reservedruck ohne Rückzugsalarm is stored but has no effect: with the mode off no Rückzugsalarm fires and Restzeit stays `T × P / P_N`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | **Decided** (A5)                                                                                            |
| 5.8  | The Trupp-Ansicht's bar splits the Einsatzzeit into Anmarsch, Einsatzziel erreicht and Rückmarsch. ~~Rückmarsch = 2 × Anmarsch + reserve.~~ Replaced: the Rückmarsch field is the Restzeit the Rückzugsdruck is worth, `P_R × T / P_N` (5.5), i.e. `P_R / P_N` of the bar (assumption, issue #55).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | [Manual] p. 11                                                                                              |
| 5.9  | ~~At most once per Anmarsch leg; a raise does not re-arm it.~~ Replaced: the Rückzugsalarm fires once. Only a pressure entry that lifts the estimate back above `P_R` re-arms it; one that leaves it at or below does not fire it again. It never fires in Rückmarsch (assumption: the user believes so but did not see it) and pauses in Bereitschaft (4.7). Rückmarsch is the only running Einsatzstatus that suppresses an alarm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | **Decided** in _Correct the simulator against the real Checkbox_                                            |
| 5.13 | ~~Armed only from Einsatzziel erreicht onwards.~~ Replaced: armed **from login**, with `P_R` = 50 bar until Einsatzziel erreicht. An untouched Trupp in Anmarsch gets the Rückzugsalarm when the estimate reaches 50 bar (`R` = 5:00 at 30 min).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | **Decided** in _Correct the simulator against the real Checkbox_                                            |
| 5.14 | When the Rückzugsalarm is armed and a pressure entry (Druck ändern, or Einsatzziel erreicht, which also sets `P_R`) leaves the estimate already at or below `P_R`, the alarm fires as soon as OK confirms it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | **Decided** (A2); amended in _Correct the simulator against the real Checkbox_                              |
| 5.10 | ~~Anmarsch → Rückmarsch directly is allowed.~~ Replaced: `Rückzug antreten` is offered only in Einsatzziel erreicht, and `Einsatzziel erreicht` only in Anmarsch. A Trupp reaches Rückmarsch only through Einsatzziel erreicht.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | [Device]; **Decided** in _Correct the simulator against the real Checkbox_                                  |
| 5.15 | ~~Every entry into Anmarsch starts a new **Anmarsch leg**.~~ Withdrawn: Bereitschaft restores the earlier Einsatzstatus (4.6), so there are no Anmarsch legs. The Anmarschdruck always runs from the Anfangsdruck.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | **Decided** in _Correct the simulator against the real Checkbox_                                            |

## 6. Prozentmodus (Einsatzzeit #4)

**Out of scope:** the Prozentmodus is not simulated ([Draw the simulator's scope](../adr/0002-draw-the-simulators-scope.md)); Einsatzzeit #4 is, with it off (§9, _Correct the simulator against the real Checkbox_). This section is kept as research only; A7 is closed without a decision.

What the manual says, in full:

- [45] Prozent Modus EZ#4: for long Einsätze the "Prozentmodus für die Alarmgrenzen" makes more sense than the 1/3 – 2/3 limits; 0 = off, 1 = on. [Manual] p. 25, 71
- [46] Reserve % EZ#4: "Flaschendruckreserve", only used when the Prozentmodus is on; 0–99 %. [Manual] p. 71
- [47] Erweiterte Alarmgrenze EZ#4: "Nach der eingestellten Zeit ertönt der erste Alarm"; 0 = off, max 240 min. [Manual] p. 71
- [48] Erweiterter Alarm Folgealarm EZ#4: time for all follow-up alarms after the first; 0 = off, max 240 min. [Manual] p. 71. The table in 9.1 numbers it **[49]**, not [48].

The manual does not say how these combine. One reading:

| #   | Rule                                                                                                                                    | Source          |
| --- | --------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| 6.1 | With [45] on, Einsatzzeit #4 ignores Alarmgrenzen #1–#4 ([65]–[68]). Instead an Alarm fires at `t_run = [47]`, then every [48] minutes. | [Assumption] A7 |
| 6.2 | [46] replaces the bar-based Reservedruck for EZ#4 in the Rückzugsalarm: `t_res = [46] % × T`.                                           | [Assumption] A7 |

## 7. Daueralarm

A Daueralarm cannot be silenced by OK; it stops only when its cause is removed (glossary).

| #   | Trigger                                                                                                                                                 | Ends when                                                                                                                   | Source                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| 7.1 | An Atemschutzträger does not log off at Einsatz beenden.                                                                                                | The missing Atemschutzträger logs off with their Tally, or a Notausschaltung (X + Check ~4 s) ends the Trupp or all Trupps. | [Manual] p. 15, 30–31       |
| 7.2 | ~~Fewer than [07] Minimale Anzahl der Truppmitglieder (≥ 2) have logged on for a Trupp.~~ Withdrawn: the device sounds no Daueralarm for this; see 7.5. | —                                                                                                                           | [Manual] p. 71–72; [Device] |

The manual does not say when either one starts. Decided (A8, device behaviour):

| #   | Rule                                                                                                                                                                                                                                                                                                                                 | Source                                                                     |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 7.3 | The logoff Daueralarm (7.1) starts when OK is pressed on ABMELDEN while any Atemschutzträger is still unmarked. ABMELDEN stays open; there is no timeout and nothing starts it before OK.                                                                                                                                            | **Decided** (A8)                                                           |
| 7.4 | The logoff Daueralarm stops as soon as every Atemschutzträger is marked; ABMELDEN then waits for OK as usual (no auto-logoff). X also stops it: marks cleared, the Trupp keeps running in its previous Einsatzstatus. A Notausschaltung of the Trupp ends it too. Pressing OK again with Atemschutzträger still missing restarts it. | **Decided** (A8)                                                           |
| 7.5 | ~~The login Daueralarm starts on OK.~~ Replaced: OK on `Trupp OK …` with fewer than [07] Atemschutzträger joined shows a framed box `Zu wenig Einsatzkräfte!` over the Anmeldefenster. No siren, no LED; the [12] delay plays no part.                                                                                               | [Device]; **Decided** in _Correct the simulator against the real Checkbox_ |
| 7.6 | ~~The login Daueralarm stops …~~ Replaced: the box stays until a Tally joins (it adds its Atemschutzträger and closes the box), OK or X. OK and X close only the box and keep the members (assumption); the Anmeldefenster then waits for OK as usual.                                                                               | [Device]; **Decided** in _Correct the simulator against the real Checkbox_ |

## 8. Acknowledging and concurrency

| #   | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Source                                                                                          |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 8.1 | Every non-Daueralarm is acknowledged with OK.                                                                                                                                                                                                                                                                                                                                                                                                                     | [Manual] p. 14, 23–28                                                                           |
| 8.2 | ~~Coincident or later Alarms of one Trupp merge into its single pending Alarm.~~ Replaced: every Alarm is its own entry in one first-in, first-out queue, even several of one Trupp. Alarms that fire in the same `tick` or on the same OK queue in the order their thresholds were crossed, ties in the order Alarmgrenze, Rückzugsalarm, Einsatzzeit erreicht, overdue repeat (assumption). A Daueralarm cannot be acknowledged with OK, so it is never queued. | **Decided** in _Correct the simulator against the real Checkbox_                                |

| 8.5 | The ALARM screen's header names the cause: `Trupp NN ALARM 1` / `ALARM 2` (Alarmgrenzen #1/#2), `RÜCKZUG`, `ALARM` (Einsatzzeit erreicht and the overdue repeats), `BEREITSCHAFT`.                                                                                                                                                                                                                                                                                | [Device] (ALARM 1/2, RÜCKZUG); **Decided** in _Correct the simulator against the real Checkbox_ |
| 8.3 | Starting a Langzeiteinsatz (any Einsatzzeit except 30 min) needs an extra OK confirmation.                                                                                                                                                                                                                                                                                                                                                                        | [Manual] p. 18                                                                                  |

## 10. Manual conflicts

- **[48] vs [49]:** 6.12.1 calls the EZ#4 follow-up alarm [48]; 9.1 calls it [49]. 6.12.1 also lists [49] as the Atemschutzflaschentyp for one Einsatzzeit ([14, 49, 53, 54]), and 9.1 has no Flaschentyp entry for Einsatzzeit #2.
- **[82] has two meanings:** in Register DRUCK it is the "Standard-Reservedruck … ohne Rückzugsalarm" (10–9999); further down the same page it is the "Flaschendruck bei Rückzugalarm (50 bar Standard)", which is [42]'s job.
- **[42] range** is "zwischen 0 und 2500 bar", implausible for 200/300 bar bottles.
- **Resolution:** neither conflict changes behaviour. The [48]/[49] numbering only touches Einsatzzeit #2 and the Prozentmodus of #4, neither of which is simulated. [82] is inert (5.12) and defaults to 50 bar. The simulator uses the 9.1 numbering wherever a number is shown.
- **Figures disagree with each other:** p. 22 shows 295 bar → 00:28:00; p. 29 shows 40 bar, 00:02:00 and a 120 bar Rückzugsdruck. Treat figure numbers as layout references, not test vectors.

## Open decisions

The decisions are recorded as ADRs in [`docs/adr/`](../adr/), under the same titles. A1 and A5 are decided in _Decide how Flaschendruck drives Restzeit and the Rückzugsalarm_; A2 and A3 in _Decide when one-shot and repeating alarms fire_; A4 and A6 in _Decide the Einsatzstatus transitions_; A8 in _Decide when a Daueralarm starts and ends_; A9 in _Fix the factory defaults the manual leaves open_ (rows marked **Decided** above).

These feed the follow-up grilling ticket.

- **A1 — Pressure and Restzeit.** Does a Flaschendruck entry recompute Restzeit as `T × P / P_N` (1.4)? If so, are Alarmgrenzen then measured against Restzeit (2.4) or elapsed time?
- **A2 — Once-only alarms.** Each Alarmgrenze and the Rückzugsalarm fire once. Is the Rückzugsalarm suppressed once the Trupp is in Rückmarsch? What happens when a pressure change moves an already-passed point forward again?
- **A3 — Interval anchoring.** Are the Regelzeit and Bereitschaft repeat alarms anchored at the triggering event or at each acknowledgement?
- **A4 — Leaving Bereitschaft.** Which Einsatzstatus does "Trupp -> Einsatz" restore?
- **A5 — Reserve conversion.** Is the Reservedruck converted to time linearly (`[42] × T / P_N`)? Should the Rückzugsdruck be shown as `[42] + 2 × (P_0 − P_Ziel)`? And which one triggers the alarm: the time comparison or the pressure comparison?
- **A6 — Anmarsch → Rückmarsch.** Is this transition allowed without passing Einsatzziel erreicht?
- **A7 — Prozentmodus semantics.** _Out of scope_ (section 6). Adopt reading 6.1/6.2, or leave Prozentmodus off (it only affects Einsatzzeit #4, 180 min on the device)?
- **A8 — Daueralarm start and cancel.** When does each Daueralarm start, and can X cancel the logoff Daueralarm?
- **A9 — Unknown defaults.** Fix values for every **unknown** row in section 9, including whether the Rückzugsalarmmodus is on for each Einsatzzeit. _Decided:_ see section 9.
